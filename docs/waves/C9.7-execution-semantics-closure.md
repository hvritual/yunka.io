## Runtime invariant

```text
PB Operation
  -> Contract Compiler
  -> immutable OperationPlan
  -> Unified Executor
       -> metadata
       -> security once
       -> idempotency claim
       -> root ExecutionScope / UoW
       -> Application / typed child composition
       -> Saga/Outbox joins current transaction
       -> atomic idempotency success staging
       -> one commit / rollback
       -> outcome
```

`framework/requestscope` remains the typed request/repository-view mechanism, but under C9.7+ it does not own the root Operation transaction lifecycle. The active root `ExecutionScope` owns the UnitOfWork/commit/rollback lifecycle; requestscope join views bind typed repositories to that current UoW.

## Explicit non-goals

- response/result replay for idempotent requests;
- distributed transaction / 2PC;
- BPMN or generic workflow engine;
- generic service locator / reflection DI;
- automatic transaction/idempotency inference from HTTP verb or method naming;
- generic data-scope SQL DSL;
- audit persistence and cache policy;
- Saga step topology graph evidence.

Canonical internal-only Operation declaration was a C9.7 non-goal and was subsequently resolved by C9.8 rather than retrofitted into C9.7.
